# Hourly production log

## A

I'm reporting production performance for a line. Each row in the production log covers one hour for one line, and `hour_start` is the start of that hour in Korea Standard Time. Please look at the four intervals from 8 a.m. up to but excluding noon on March 2. `units_produced` is the number of units made during that hour. Give me the output per operating hour by dividing total output for hours marked `open` by the total number of those hours.

## B

Each row in the production log covers one hour. `units_produced` is the number of units made that hour, and `open` means the line was operating. I'm reporting performance for the period covered by the log. Please calculate hourly throughput.

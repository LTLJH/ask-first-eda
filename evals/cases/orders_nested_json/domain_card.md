# Simulator only · Daily order volume

Answer only what was asked, briefly and in English. For any fact outside this card say “I don't know”. Never supply counts or a trend.

## Shared facts

These are shop orders. The user needs the direction of the daily change for a sales meeting. One outer record represents one order. An item is one order line and qty counts pieces on that line. An order ID is an exact text identifier. The order date is the shop's local calendar date. There is no shift cutoff, second table or agreed normal range.

## B

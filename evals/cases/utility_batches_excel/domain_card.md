# Simulator only · Batch steam consumption

## B

Reply to the question asked, in English. For anything outside these facts say “I don't know”. Do not initiate the interview or give computed results.

| If asked about | Fact to disclose |
|---|---|
| Meeting and measures | The meeting compares daily plant steam kg per tonne of finished product. The user also wants the unweighted mean of defined batch rates. |
| Grain and key | The batches sheet records finished batches or shutdown intervals. Each distinct reading ID is a measured steam increment assigned to one batch ID. Several increments can belong to a batch. Match exact text IDs. |
| Duplicate | Identical records for the same batch are an export replay. Count the first once. |
| Units | Each production value uses the unit on its row. One metric tonne equals 1,000 kg. |
| Day boundary | When asked which day owns a crossing batch, reply “Assign all production and steam consumption to the date the batch started in Korea Standard Time”. |
| Zeros | A shutdown has no production or steam draw. Running batches can use stored heat and finish with positive output and zero fresh steam. Explicit zeros are measured. |
| Large draw | B-0020 is a confirmed large H run. Its reported output and draw are valid. There is no agreed numeric cutoff. |
| Efficiency | The two products have different heat requirements. No controlled performance test or external efficiency target is available. |

Assumptions & limitations

  • All 34,560 records decoded with seven typed fields, four equal row groups and no unread data. The file has matching PAR1 signatures, zero duplicate rows, zero duplicate pump timestamps, zero missing time slots and consistent unit fields. Current and timestamp fields have zero missing values. There are 210 blank commands and 54 blank vibration values across 264 distinct rows.
  • P-02 is the first inspection priority. Review the September 17 stop with the operating log, as only P-02 was stopped from 10:00 through 11:25 local time (18 readings, rows 13,369–13,386). The records establish no cause for the stop or for the earlier and later vibration episodes.
  • P-02 Sep 04, 09:10–10:40 had 19 alarm-or-higher readings, of which 8 reached danger. sensor_readings.parquet rows 9615–9633.
  • P-02 Sep 12, 15:20–17:15 had 24 alarm-or-higher readings, of which 9 reached danger. sensor_readings.parquet rows 11993–12016.
  • P-02 Sep 24, 01:35–02:55 had 17 alarm-or-higher readings, of which 7 reached danger. sensor_readings.parquet rows 15284–15300.
  • P-03 warrants inspection under the two-week rule. The daily running median increased at every daily comparison from September 6 through September 30. The first caution reading was September 12 at 01:00 (row 20,461). Daily medians stayed above caution from September 15 to 30. The peak was 4.397506 mm/s RMS.
  • Verify the P-01 vibration channel and check for any known work at the September 20 midnight change. Rows 5,472–5,473 show the step from 2.048109 to 0.080460 mm/s RMS between consecutive readings. Stable running current makes the low values worth validating with an independent reading.
  • P-04 shows no inspection trigger in the available readings. The vibration channel was unobserved September 10, 11:15–15:40, during 54 running samples. Check that data gap.
  • Vibration thresholds are inclusive and counts are cumulative. Limits apply to all running vibration samples, including restarts. Consecutive breach windows use five-minute adjacency. Window endpoints are sample times.
  • The first 10 minutes are represented by elapsed times of 0 and 5 minutes after each observed stopped-to-running transition. September opens with all pumps already recorded as running, with earlier restart history unavailable.
  • Current flags use each pump’s September steady 25th and 75th percentiles and three interquartile ranges on each side. These screening results carry no engineering limit or diagnosis. Daily medians summarize trend using available operating readings on each local date.
  • A separate distribution view and all-month correlation were omitted because the maintenance decisions depend on the timing of changes and the current excursions during alarms.

import pandas as pd
import numpy as np

d = pd.read_parquet('../sensor_readings.parquet')
d['row'] = np.arange(1, len(d) + 1)
d = d.sort_values(['asset_id', 'ts'])
g = d.groupby('asset_id')
rated = d.asset_id.map({'P-01': 42, 'P-04': 31})
assert rated[d.run_cmd.isna()].notna().all()
d['running'] = d.run_cmd.eq(1) | (d.run_cmd.isna() & d.current_a.gt(.2 * rated))
prior = g.running.shift()
starts = d.running & prior.eq(False)
latest_start = d.ts.where(starts).groupby(d.asset_id).ffill()
d['transient'] = d.running & (d.ts - latest_start).lt(pd.Timedelta(minutes=10))
d['day'] = d.ts.dt.strftime('%Y-%m-%d')
d['steady'] = d.running & ~d.transient
d['vibration'] = d.vib_rms_mm_s.where(d.running)
d['steady_current'] = d.current_a.where(d.steady)
d['caution'] = d.vibration.ge(2.8)
d['alarm'] = d.vibration.ge(4.5)
d['danger'] = d.vibration.ge(7.1)
daily = d.groupby(['asset_id','day']).agg(vib=('vibration','median'), n=('vibration','count'), amps=('steady_current','median'))
q = g.steady_current.quantile([.25,.5,.75]).unstack()
d['iqr'] = d.asset_id.map(q[.75]-q[.25])
d['lo'] = d.asset_id.map(q[.25])-3*d.iqr
d['hi'] = d.asset_id.map(q[.75])+3*d.iqr
d['current_flag'] = d.steady & ((d.current_a < d.lo) | (d.current_a > d.hi))

def episodes(mask):
    subset = d.loc[mask].copy()
    changes = subset.asset_id.ne(subset.asset_id.shift()) | subset.ts.diff().ne(pd.Timedelta(minutes=5))
    return subset.groupby(changes.cumsum()).agg(asset=('asset_id','first'), start=('ts','first'), end=('ts','last'), n=('row','size'), first=('row','first'), last=('row','last'), vib=('vibration','max'), min_a=('current_a','min'), max_a=('current_a','max'))

def loc(data):
    rows = sorted(data.row)
    blocks = []
    for row in rows:
        if blocks and blocks[-1][1] + 1 == row:
            blocks[-1][1] = row
        else:
            blocks.append([row, row])
    return [src + ' rows ' + ', '.join(str(a) if a == b else f'{a}–{b}' for a, b in blocks)]

def chart(id, question, columns, n, reason, observation, interpretation, type='line_time'):

        question=question, source_columns=columns, n_used=int(n), n_excluded=int(n_total-n),
        exclusion_reason=reason, observation=observation, domain_interpretation=interpretation))

def finish(fig, id):

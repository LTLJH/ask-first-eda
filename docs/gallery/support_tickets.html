Assumptions & limitations

  • Coverage spans all 91 KST calendar dates in Q2 2025. Count each ticket by its receipt date and use the file's recorded outcomes up to quarter-end.
  • First responses use 63 business dates: weekdays 09:00–18:00 KST, excluding May 5 and June 6. Targets are inclusive and priority-based.
  • For resolution, the stated duplicate exclusion was applied only to response SLA. Resolution timing includes all tickets with a first recorded resolution, including 13 linked duplicates. The 104 reopened tickets have their later work outside this timing measure.
  • Resolution attainment is unavailable because the policy targets are unknown. The adjusted-duration distribution uses the resolved cohort, and 147 tickets lacking resolution have no duration in it.
  • Assigned is elapsed time in a logged status, including time outside business hours. The ticket file provides no agent rosters or measured active work time. Use the P2 receipt-window comparison to identify where to review coverage and the Assigned intervals to locate the largest elapsed status.
  • The outside-hours attainment difference varies by priority. P2 was 78.28% outside hours and 94.87% during hours. P3 was 89.66% outside hours and 85.42% during hours. June included 156 eligible P1 tickets, compared with 36 in April and 36 in May. The comparisons reflect the observed mix.
  • Quality checks found zero malformed lines, repeated ticket IDs, exact repeated records, or timestamp parsing failures in the analyzed fields. The 15 duplicate links all point to originals. Event histories are chronological and agree with receipt and first resolution fields.
  • Of 1,500 records, 72 lack a first-response timestamp and 147 lack a first-resolution timestamp, affecting 147 distinct tickets. The 107 missing customer tiers and 1,327 missing CSAT values are outside the measures. The optional duplicate_of key is absent on 1,485 records.
  • The resolution histogram retains 37 adjusted durations above the upper 1.5-IQR fence. The reported median and 90th percentile both use the full resolved cohort.
  • A separate correlation view was omitted because the staffing comparison uses categorical intake windows and priorities. A separate status frequency chart was omitted because the delay question uses elapsed status time.

# Run from eda-work with python3 -I analyze.py
import json
from collections import Counter
from pathlib import Path

import pandas as pd

SOURCE = Path("../tickets.jsonl")
ZONE = "Asia/Seoul"
START = pd.Timestamp("2025-04-01", tz=ZONE)
CUTOFF = pd.Timestamp("2025-07-01", tz=ZONE)
HOLIDAYS = {"2025-05-05", "2025-06-06"}
TARGET = {"P1": 60, "P2": 240, "P3": 480, "P4": 1440}
lines = SOURCE.read_text(encoding="utf-8").splitlines()
records = [json.loads(line) for line in lines]
d = pd.DataFrame(records, index=pd.Index(range(1, len(records) + 1), name="source_line"))
parse_failures = {}
for col in ["created_at", "first_response_at", "resolved_at"]:
    parsed = pd.to_datetime(d[col], utc=True, errors="coerce").dt.tz_convert(ZONE)
    parse_failures[col] = int((parsed.isna() & d[col].notna()).sum())
    d[col] = parsed
assert not any(parse_failures.values())
duplicate = d.duplicate_of.notna()
assert d.ticket_id.is_unique and d.ticket_id.notna().all()
assert d.loc[duplicate, "duplicate_of"].isin(d.loc[~duplicate, "ticket_id"]).all()
assert (d.created_at.ge(START) & d.created_at.lt(CUTOFF)).all()

# Build business intervals in KST and intersect them with each response clock.
days = pd.date_range(START, CUTOFF, freq="B", inclusive="left")
windows = [
    (day + pd.Timedelta(hours=9), day + pd.Timedelta(hours=18))
    for day in days if day.strftime("%Y-%m-%d") not in HOLIDAYS
]
def business_minutes(start, stop):
    return sum(max(0, (min(stop, end) - max(start, begin)).total_seconds()) / 60
               for begin, end in windows if start < end and stop > begin)

responded = d.first_response_at.notna()
assert d.loc[responded, "first_response_at"].ge(d.loc[responded, "created_at"]).all()
assert d.loc[responded, "first_response_at"].lt(CUTOFF).all()
d["target_min"] = d.priority.map(TARGET)
assert d.target_min.notna().all()
d["business_min"] = [
    business_minutes(a, b) for a, b in zip(d.created_at, d.first_response_at.fillna(CUTOFF))
]
d["late_unanswered"] = ~responded & d.business_min.ge(d.target_min)
d["eligible"] = ~duplicate & (responded | d.late_unanswered)
d["met"] = d.eligible & responded & d.business_min.le(d.target_min)
d["missed"] = d.eligible & ~d.met
d["month"] = d.created_at.dt.strftime("%Y-%m")
d["receipt"] = [
    "Business hours" if any(a <= t < b for a, b in windows) else "Outside business hours"
    for t in d.created_at
]
d["recorded"] = responded

# Use source event order. Each interval inherits the status at its start.
all_status = Counter()
kinds = ("new", "assigned", "waiting_customer")
stages = []
reopened = []
for line, row in d.iterrows():
    events = [(pd.Timestamp(event["at"]).tz_convert(ZONE), event["status"]) for event in row.events]
    all_status.update(status for _, status in events)
    assert events[0] == (row.created_at, "new")
    assert all(left[0] <= right[0] for left, right in zip(events, events[1:]))
    first = next((j for j, (_, status) in enumerate(events) if status == "resolved"), None)
    if any(status == "reopened" for _, status in events):
        reopened.append(line)
    if first is None:
        assert pd.isna(row.resolved_at)
        continue
    assert events[first][0] == row.resolved_at and row.resolved_at < CUTOFF
    hours = dict.fromkeys(kinds, 0.0)
    for (begin, status), (end, _) in zip(events[:first], events[1:first + 1]):
        hours[status] += (end - begin).total_seconds() / 3600
    gross = (row.resolved_at - row.created_at).total_seconds() / 3600
    assert abs(gross - sum(hours.values())) < 1e-8
    stages.append({
        "source_line": line, "gross_h": gross, **hours,
        "adjusted_h": gross - hours["waiting_customer"]
    })
resolved = pd.DataFrame(stages).set_index("source_line")
d = d.join(resolved, validate="one_to_one")
sla = d[d.eligible].copy()
raw = sla[sla.recorded].copy()
raw["target_multiple"] = raw.business_min / raw.target_min

def breakdown(columns):
    table = sla.groupby(columns, dropna=False).agg(
        eligible=("met", "size"), met=("met", "sum"), missed=("missed", "sum"),
        unanswered_misses=("late_unanswered", "sum"), recorded=("recorded", "sum")
    )
    table["percent"] = 100 * table.met / table.eligible
    return table

monthly = breakdown("month")
monthly.reset_index().assign(month_start=lambda g: g.month + "-01").to_csv("monthly.csv", index=False)
raw[["target_multiple"]].to_csv("response_observations.csv")
resolved[["adjusted_h"]].to_csv("resolution_observations.csv")
resolved[list(kinds)].rename(columns={
    "new": "New", "assigned": "Assigned", "waiting_customer": "Waiting for customer"
}).reset_index().melt(id_vars="source_line", var_name="status", value_name="elapsed_h").to_csv(
    "stage_observations.csv", index=False
)

if __name__ == "__main__":
    print("Missing fields:", pd.DataFrame(records).isna().sum().to_dict())
    print("Exact repeated records:", len(records) - len({json.dumps(r, sort_keys=True) for r in records}))
    print("Events:", all_status, "reopened tickets:", len(reopened))
    print("Scopes:", len(d), int(duplicate.sum()), len(sla), len(raw), len(resolved))
    print("Overall:", int(sla.met.sum()), int(sla.missed.sum()), int(sla.late_unanswered.sum()))
    for grouping in ["priority", "assignee_team", "channel", "receipt", "month",
                     ["receipt", "priority"], ["month", "priority"]]:
        print(breakdown(grouping).to_string())
    print("Resolution", resolved.describe(percentiles=[.25, .5, .75, .9]).to_string())
    print("Resolution sums", resolved.sum().to_dict())
    print("Positive waiting count", int(resolved.waiting_customer.gt(0).sum()))
    print("Resolution by team", d.groupby("assignee_team").adjusted_h.agg(["count", "median"]).to_string())

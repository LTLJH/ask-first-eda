가정과 한계

  • 날짜 행 43개에 중복 날짜나 빈 일자·생산량·가동시간 원본 셀이 없었습니다. 생산량 단위는 kg와 t였고, 업무상 해당 없음 2건 외 날짜·수치 파싱 실패는 0건입니다. 가동시간은 보전일 0시간을 포함해 0~20시간입니다. 비고가 빈 날짜 행은 41개입니다.
  • daily_report.xlsx 3월!B17 주간 소계는 62,500 kg이며, B12:B16 날짜 행의 합계는 61,500 kg입니다. 차이 1,000 kg. 두 시트의 월 합계는 날짜 행 집계와 일치합니다.
  • 기록 기간 중 날짜 행이 없는 16일은 모두 주말입니다. 이 날짜는 계획 가동시간에 포함하지 않았습니다. 날짜 행이 있는 보전일은 포함했습니다.
  • 결과의 업무 활용처는 미정입니다. 월별 지표에는 기간 중 날짜 행 수 차이가 반영됩니다.
  • 분포도와 상관관계 그림은 생략했습니다. 일별 그림은 원래 날짜 순서를 보여주며, 요청한 비교는 월별 막대 그림에서 확인할 수 있습니다.

def source_ref(sheet, rows, columns):
    groups = []
    start = end = rows[0]
    for row in rows[1:]:
        if row == end + 1:
            end = row
        else:
            groups.append((start, end))
            start = end = row
    groups.append((start, end))
    ranges = [f"{columns}{lo}" if lo == hi else f"{columns}{lo}:{columns}{hi}" for lo, hi in groups]
    return f"{source} {sheet}!{', '.join(ranges)}"


def create_figure():
    fig, ax = plt.subplots(figsize=(9.4, 3.7), layout="constrained")
    ax.set_axisbelow(True)
    ax.grid(axis="y", color="#e1e8ec")
    return fig, ax


def save(fig, chart_id):
    fig.savefig(delivery / "figures" / f"{chart_id}.png", facecolor="white")
    plt.close(fig)

        "exclusion_reason": reason, "observation": observation, "domain_interpretation": caption,
    }

        mass_column, hours_column = f"{line} 생산량", f"{line} 가동시간"
        assert frame[hours_column].between(0, hours_per_day).all()
        assert frame[mass_column].isna().equals(frame[f"{line} 생산량 상태"].eq("해당 없음"))
        mass_rows = frame.loc[frame[mass_column].notna(), "_source_row"].tolist()
        all_rows = frame["_source_row"].tolist()
        mass = int(frame[mass_column].sum(min_count=1))
        hours = int(frame[hours_column].sum())
        plan = len(all_rows) * hours_per_day
        production[sheet, line] = mass
        rates[sheet, line] = hours / plan * 100

            dict(name=f"{sheet} {line} 생산량", definition=f"{len(mass_rows)}개 날짜 행에 기록된 생산량 합계. t는 1,000을 곱해 kg으로 환산. 합계 지표에는 분자와 분모가 적용되지 않음.",

                 numerator=hours, denominator=plan, value=rates[sheet, line], unit="%", depends_on_ambiguity_ids=[],

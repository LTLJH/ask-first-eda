Assumptions & limitations

  • The complete comma-delimited file decoded in Windows-1252, with 8,760 records and 14 fields. The CSV extension matches the content. All lines were read.
  • Dates parse day-first, from 1 December 2017 through 30 November 2018. Every recorded date has 24 distinct hour labels. Across the file there are zero blank cells, zero exact duplicate rows and zero duplicate Date and Hour keys.
  • All dates and hours used parsed successfully. All rental values are nonnegative integers with one consistent count unit. All 295 zero counts occur on suspension rows. Among operating rows, 152 counts exceeded the exploratory upper fence of 2,389 and were retained.
  • A05 records the unknown time zone. Clock labels and calendar day types follow the file. Verify the clock basis before mapping the profile to local rosters. Weekday means Monday through Friday and weekend means Saturday or Sunday. Holiday rows retain their recorded calendar day type.
  • Completed systemwide rentals are a proxy for service activity. Pickup timing, station-level flows, inventory, unmet demand and redistribution workload are unavailable in these records, so these comparisons identify candidate coverage windows. Crew sizes and routes require workload and station data.
  • Season comparisons describe this year's operating hours. Suspension timing and weekday mix can vary across seasons. The comparisons describe the observed grouping and cannot identify causes.
  • A compact season table provides exact comparisons with operating-hour denominators. A category-frequency chart would duplicate the suspension totals, and a weather-relationship plot answers a different decision question.
  • Totals, counts, quantiles and maxima are direct summaries, with no numerator or denominator fields. Hourly means use the same eligible rows for both components.

def ranges(rows):
    spans = []
    for _, group in groupby(enumerate(rows.index), lambda pair: pair[1] - pair[0]):
        block = [line for _, line in group]
        spans.append(str(block[0]) if len(block) == 1 else f"{block[0]}–{block[-1]}")
    return f"{source} lines " + ", ".join(spans)

open_ref = ranges(operating)
closed_ref = ranges(suspended)
metrics = []

def metric(name, definition, value, unit, refs, numerator=None, denominator=None):
    metrics.append(dict(name=name, definition=definition, value=value, unit=unit,
                        numerator=numerator, denominator=denominator, source_refs=refs,
                        depends_on_ambiguity_ids=[], condition=None))
    return value

def mean(name, rows, selection, source_ref):
    total = int(rows[count].sum())
    hours = len(rows)
    return metric(name, f"Sum of {count} divided by the number of operating rows, one per hour. {selection}.",
                  total / hours, "completed rentals per operating hour", [source_ref], total, hours)

def peak(group):
    stats = all_hours if group is None else day_hours.loc[group]
    hour = int(stats["mean"].idxmax())
    rows = operating.loc[operating["Hour"].eq(hour)]
    if group is not None:
        rows = rows.loc[rows["Day type"].eq(group)]
    value = mean(f"{group or 'Overall'} mean at {hour:02}:00", rows,
                 f"Highest mean over the 24 recorded hour labels within {group or 'all operating dates'}",
                 f"{open_ref}, filtered to Hour = {hour}" + (f" and Day type = {group}" if group else ""))
    point = stats.loc[hour]
    assert value == point["mean"] and len(rows) == point["hours"]
    return hour, int(point["total"]), int(point["hours"]), value

overall_peak = peak(None)
weekday_peak = peak("Weekday")
weekend_peak = peak("Weekend")
mean("Overall operating-hour mean", operating, "All dates in the source", open_ref)

for group in ("Weekday", "Weekend"):

    mean(f"{group} mean at 08:00", rows, f"{group} operating rows at Hour = 8",
